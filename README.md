# DeporPlaza Lima

DeporPlaza Lima es una aplicación web desarrollada en Java con Spring Boot que permite la gestión y reserva de campos deportivos de manera rápida y sencilla.

## Funcionalidades principales

* Registro e inicio de sesión de usuarios.
* Gestión de usuarios y roles (Administrador y Usuario).
* Gestión de campos deportivos.
* Gestión de horarios disponibles.
* Registro y administración de reservas.
* Dashboard administrativo con estadísticas y gráficos.
* Visualización de disponibilidad mediante FullCalendar.
* Validaciones de formularios y control de acceso con Spring Security.

## Tecnologías utilizadas

* Java 21
* Spring Boot
* Spring Security
* Spring Data JPA
* Thymeleaf
* MySQL
* Maven
* Bootstrap 5
* JavaScript
* FullCalendar
* Chart.js

## Arquitectura

El proyecto sigue el patrón de arquitectura MVC (Modelo - Vista - Controlador), utilizando una estructura basada en capas:

* Controladores
* Servicios
* Repositorios (DAO)
* Entidades
* Vistas Thymeleaf
